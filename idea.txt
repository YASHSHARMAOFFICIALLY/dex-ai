- Unknown coding harness (opencode, Mastra, Vercel AI SDK). Has to be which one that can use subscription from AI provider (claude code, codex, opencode go), as well as support OpenAI, OpenRouter api

- Observability (better with existing library): 
+ log: prompt, reasoning, tool call
